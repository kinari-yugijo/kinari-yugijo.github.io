VRCHAT WORLD GIMMICK

ChronoSlate Manual

A wall-sized clock for your VRChat world. Everyone in the instance sees the same time.

--:--

This is roughly how it reads. The digits glow, and the frame comes in 24 finishes.

ChronoSlate shows VRChat network time, not each player's local clock. Agreements that live inside a world — "we break at 23:00" — only work if everyone is looking at the same number. That is why this gimmick deals in shared time only.

Drop it in, set the time zone, done. There is no syncing to configure and no events to wire up.

📦 Requirements

Install these in your project first. They are not included in this package.

ItemVersion
Unity2022.3.22f1
VRChat SDK - Worlds3.10.3
Poiyomi Toon Shader9.3.64

Poiyomi Toon is required. Without it every material renders magenta. Add the VCC repository from poi.moe to install it.

Quest (Android) is not supported, because Poiyomi does not run on Quest. Use this in PC worlds.

Nothing else is required — not even TextMeshPro.

🔰 Setup

  1. Open your world project in VCC (Creator Companion) and confirm the requirements above are installed.
  2. Import ChronoSlate_v1.0.0.unitypackage via Assets > Import Package > Custom Package. It unpacks to Assets/KinariYugijo/ChronoSlate/.
  3. Drag Assets/KinariYugijo/ChronoSlate/Prefabs/ChronoSlate.prefab into your scene hierarchy.
  4. Position and scale it, then set your time zone below.

⚙️ Time zone

Select the prefab root ChronoSlate and set the field on ChronoSlateCore.

FieldMeaningDefault
UTC Offset (hours)Time zone of the displayed time9

Decimals are supported, so 30- and 45-minute offsets work. Negative values are fine too.

RegionValue
Japan (JST)9
India (IST)5.5
Nepal (NPT)5.75
UK (GMT)0
US West Coast (PST)-8

The display shows hours : minutes. Seconds are not shown.

📐 Size & placement

The default size is roughly 5.03m × 1.82m × 0.49m — sized for a large wall. Scale the prefab root down for a desk or a smaller wall.

Mount it, stand it, or hang it; placement is up to you. It has no colliders and no interactions, so it never blocks player movement.

🎨 Changing the look

Swap the material on a Renderer and the finish changes. The Common materials work anywhere — frame, digits, or backplate. They are not tied to a specific part.

Materials/Common — 24 finishes

  • Fabric01–06
  • Glass01–02
  • Lava01
  • Metal01–05
  • Stone01–05
  • Wood01–05

Materials/Back — 6 backplate finishes

  • Emission01
  • Emission02
  • Emission03
  • Emission04
  • Emission05
  • Emission06

Materials/Number — 6 digit finishes

  • Emission1
  • Emission2
  • Emission3
  • Glass1
  • Glitter1
  • White

The glass finishes are expensive to render. Common_Glass01, Common_Glass02 and Number_Glass1 use Poiyomi Toon Grab Pass. GrabPass costs a lot of frame time and can look wrong inside mirrors. Pick another finish if your world is tight on performance.

❓ FAQ

The time is wrong

Check the UTC offset. Japan Standard Time is 9.

Everything is magenta

Poiyomi Toon is not installed. See Requirements.

Does it work on Quest?

No. Poiyomi does not support Quest.

Can it show seconds?

No. The display is four digits, fixed to hours : minutes.

Can each player see their own local time?

No. ChronoSlate is built around shared time only.
